## 用語

| 用語 | この文書での意味 |
|---|---|
| 弾幕 | あらかじめ保存して呼び出す、1行の入力文字列 |
| 配信者 | アプリ内で弾幕をまとめる管理対象。名前は自分で付けられる |
| チャンネル | YouTube側のチャンネル。配信者と連携すると自動選択に使える |
| パレット | 弾幕の入力と、今回のリアクション実行を行う画面 |
| 編集対象 | 管理画面で編集する共通弾幕または配信者。入力対象とは独立 |
| ボタン登録 | ブラウザー内の5種類のリアクションを識別する情報。チャンネル連携とは別 |
| ワーカー | ブラウザーの確認・操作を担当する補助のPowerShellプロセス |

利用手順の正本は利用者向けページ、仕様値はリファレンス、内部の制約は設計資料です。変更履歴には、その版で変わったことを記録します。
