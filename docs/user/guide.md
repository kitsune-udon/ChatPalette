# 弾幕と配信者

[文書一覧](../index.md) · [操作・設定リファレンス](reference.md)

以下のキーは初期割当です。変更済みの場合は自分の割当を使ってください。現在のキーは「管理・ヘルプ」→「ショートカットを管理」で確認・変更できます。

## 共通と配信者別を使い分ける

「👏👏👏👏👏👏」のように多くのチャンネルで使うものは、**共通の弾幕**に登録します。特定の配信者だけで使う文字列は、その配信者の弾幕に登録します。

パレットには共通弾幕と、現在の入力対象に対応する配信者別弾幕が表示されます。管理画面で編集対象を変えても、パレットの入力対象をその配信者へ切り替える操作にはなりません。

## 弾幕を追加する

1. パレットの「弾幕を追加・編集」を押します。
2. 管理画面上部で「共通の弾幕」または編集したい配信者を選びます。
3. 「追加…」で弾幕名と本文を入力します。本文は1行です。
4. 必要ならキーの割当を選び、「保存」を押します。
5. 「パレットへ戻る」で一覧を確認します。

保存した内容は再起動後も残ります。配信者別の弾幕がパレットに出ない場合は、画面上部の入力対象を確認してください。検索文字列によって絞り込まれている場合もあります。

パレットで弾幕を選択してから「弾幕を追加・編集」を開くと、その弾幕の編集対象と行を開きます。未選択の場合は入力対象を使い、利用できる入力対象がなければ共通弾幕を開きます。開いた後も編集対象欄で切り替えられます。

## 動画に合わせて配信者を自動選択する

1. 連携したいチャンネルの動画をブラウザーで開きます。
2. Ctrl＋Alt＋Qでパレットを開き、「チャンネル連携…」を押します。狭い画面では「連携…」と表示されます。
3. 新しい配信者として登録するか、既存の配信者へ連携するかを選びます。
4. 名前・現在の連携・変更後のチャンネルを確認し、「連携する」を押します。
5. 管理画面でその配信者の弾幕を追加し、「パレットへ戻る」を押します。

自動判別では、表示中の動画のチャンネルと登録済みの連携を照合します。配信者名や動画タイトルが似ているだけでは選択しません。チャンネルが未連携、または判別できない場合、パレットでは共通弾幕のみを使います。

連携は1配信者につき1チャンネルです。既存の連携を変更すると、以前のチャンネルではその配信者が自動選択されなくなります。同じチャンネルを複数の配信者へ重複登録することはできません。

## チャンネル連携を使わず手動で選ぶ

パレットの「自動判別」を「手動選択」に切り替え、隣の欄で配信者を選びます。連携がなくても、その配信者の弾幕を使えます。動画を変えても自動では切り替わらないため、入力前に対象を確認してください。

## 弾幕を入力する

1. YouTubeのチャット欄・コメント欄・返信欄をクリックします。
2. Ctrl＋Alt＋Qでパレットを開きます。
3. 弾幕を選び、プレビューで本文を確認します。名前・本文の検索も使えます。
4. 「選んだ弾幕を入力」を押します。入力直前にIMEをオフにし、入力後もオフのままです。
5. YouTube側で内容を確認して送信します。

入力時に動画と入力欄を確認します。検索欄・アドレス欄や識別できない欄には入力しません。検証と文字入力は別の処理なので、処理中に入力欄を切り替えないでください。既に文字がある場合、入力先のカーソル位置や選択状態によって挿入・置換されます。

チャット欄には **Ctrl＋Alt＋F** で移動できます。**Ctrl＋Alt＋C** はチャット欄へ移動して未送信の入力内容を消します。コメント・検索欄のクリアには使いません。

キーを割り当てた弾幕は、YouTubeの入力欄をクリックして[弾幕キー](reference.md#ショートカット)を押すことでも入力できます。チャットでは[フォーカスキーに続けて弾幕キーを押す](reference.md#フォーカスから続けて弾幕を入力する)操作も使えます。

編集画面を開いている場合は閉じ、リアクション処理中は停止または完了してから入力してください。操作を受け付けられない場合は、表示された案内を確認してください。

## 編集・整理する

管理画面の「弾幕・配信者」で対象と行を選んで操作します。

| 操作 | 結果 |
|---|---|
| 編集…／行をダブルクリック | 名前・本文・キー割当を変更。保存ボタンで確定 |
| 複製 | コピーを追加。コピーにはキー割当を引き継がない |
| 削除 | 選択した弾幕を削除 |
| 上へ／下へ | 保存順を変更。弾幕に付いているキー割当は維持 |
| 別の対象へ移動… | 共通または別の配信者へ移動。元の一覧から外れ、キー割当を解除 |
| 配信者を追加 | 名前を付けて新しい管理対象を作成 |
| 配信者の設定… | 名前・チャンネル連携・配信者の削除を扱う |

キー割当は並び順とは独立しています。同じ対象内ですでに使われている割当を別の弾幕へ付けると、以前の弾幕からその割当が外れます。保存前の案内で付け替え先を確認できます。

配信者を削除すると、その配信者の弾幕も削除されます。共通弾幕は配信者が0件でも使用できます。

## 保存と取り消し

一覧から行う複製・削除・上下移動などは、操作が成功すると自動保存されます。編集ダイアログの入力途中は、「保存」を押すまで確定しません。変更してから「キャンセル」・×・Escで閉じると、破棄するか確認します。「いいえ」で入力を保持して編集へ戻れます。変更がなければ確認せず閉じます。

管理画面の取り消しボタンで、弾幕・配信者の直近の変更を戻せます。履歴はアプリ起動中の最大30件で、編集対象をまたいで共有されます。再起動すると履歴は失われます。リアクションの標準設定などは、この取り消しの対象外です。

長く保管したい状態は[バックアップ](maintenance.md#バックアップする)を使用してください。
