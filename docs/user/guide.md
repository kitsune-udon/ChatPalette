# 弾幕と配信者

[文書一覧](../index.md) · [キー・設定](reference.md)

以下のキーは初期割当です。変更済みなら「ショートカットを管理」で現在のキーを確認します。

## 共通と配信者別を使い分ける

多くのチャンネルで使う本文は「共通の弾幕」、特定の配信者用はその配信者へ登録します。パレットは共通と入力対象の弾幕を表示します。管理画面の編集対象を変えても入力対象は変わりません。

## 弾幕を追加する

1. パレットの「弾幕を追加・編集」を押します。
2. 「共通の弾幕」または配信者を選びます。
3. 「追加…」で名前と1行の本文を入力します。
4. 必要ならキー割当を選び、「保存」を押します。
5. 「パレットへ戻る」で確認します。

保存後は再起動しても残ります。見つからない場合は入力対象と検索を確認してください。パレットで弾幕を選んでから管理画面を開くと、その対象と行を開きます。未選択なら入力対象、対象がなければ共通を開きます。

## 動画に合わせて配信者を自動選択する

1. 連携するチャンネルの動画を開きます。
2. Ctrl＋Alt＋Q→「チャンネル連携…」（狭い画面では「連携…」）を押します。
3. 新しい配信者か既存の配信者を選びます。
4. 名前・現在と変更後の連携を確認して「連携する」を押します。
5. その配信者の弾幕を追加します。

動画のチャンネルと登録済み連携を照合します。名前やタイトルの類似では選びません。未連携・判別不能なら共通だけを使います。

「配信者の設定…」→「チャンネルと連携…」でも同じ画面を開き、管理中の配信者を初期選択します。1配信者につき1チャンネルで、同じチャンネルを重複登録できません。連携を変えると以前のチャンネルでは自動選択しなくなります。

## チャンネル連携を使わず手動で選ぶ

パレットで「自動判別」を「手動選択」に切り替え、配信者を選びます。動画を変えても自動で切り替わらないため、入力前に対象を確認します。

## 弾幕を入力する

1. YouTubeのチャット・コメント・返信欄をクリックします。
2. Ctrl＋Alt＋Qでパレットを開きます。
3. 弾幕を選び、本文のプレビューを確認します。
4. 「選んだ弾幕を入力」を押します。
5. YouTube側で確認して送信します。

入力前に動画と入力欄を確認し、IMEをオフにします。入力後もオフです。検索・アドレス欄や識別できない欄には入力しません。カーソル位置と選択に応じて挿入・置換します。処理中に入力先を切り替えないでください。

タブ・改行・Backspaceなどの制御文字がある場合は本文全体の入力を拒否します。本文を編集して取り除いてください。保存値を自動変更しません。

Ctrl＋Alt＋Fはチャットへ移動、Wは移動して未送信内容をクリア、Eは現在のチャットへEnterを1回送ります。コメント・検索欄のクリアや送信には使えません。[条件と連続操作](reference.md#ページ操作の条件)を確認してください。

[弾幕キー](reference.md#ショートカット)でも入力できます。編集画面を閉じ、リアクションは停止・完了してから操作します。

## 編集・整理する

| 管理画面の操作 | 結果 |
|---|---|
| 編集…／ダブルクリック | 名前・本文・キーを変更し、保存で確定 |
| 複製 | キー割当なしのコピーを追加 |
| 削除 | 選択弾幕を削除 |
| 上へ／下へ | 順序を変更し、キー割当を維持 |
| 別の対象へ移動… | 元から外して移動し、キー割当を解除 |
| 配信者を追加 | 新しい管理対象を作成 |
| 配信者の設定… | 名前・連携を変更、配信者を削除 |

配信者の削除は所属する弾幕も削除します。共通は配信者0件でも使えます。キーの内容は[割当手順](reference.md#弾幕キーの内容を選ぶ)でも変更できます。

## 保存と取り消し

一覧操作は成功時に自動保存します。編集途中は「保存」まで確定しません。キャンセル・×・Escでは未保存変更の破棄を確認し、「いいえ」で下書きと画面を保持します。

取り消しは弾幕・配信者・割当・名前・連携の直近30件です。対象をまたいで共有し、値が変わらない保存では増えません。再起動で失われ、リアクション標準設定などは対象外です。保管には[バックアップ](maintenance.md#バックアップする)を使います。
