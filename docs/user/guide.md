# 利用ガイド

[READMEへ戻る](../../README.md) · [困ったとき](maintenance.md)

## パレットで入力する

1. YouTubeの動画ページで、チャット欄またはコメント欄をクリックします。
2. **Ctrl＋Alt＋Q** でパレットを開きます。
3. 配信者別・共通の一覧から弾幕を選び、下の本文を確認します。検索は弾幕名と本文が対象です。
4. 「選んだ弾幕を入力」を押します。パレットが隠れ、元の入力欄へ文字列を入力します。
5. YouTube側で内容を確認して送信します。

一覧の選択だけでは入力しません。「選んだ弾幕を入力」はEnterでも実行できます。入力先は動画ページのチャット・コメント・返信欄です。検索欄、アドレス欄、識別できない入力欄を検出した場合は停止します。検証と文字入力は別処理なので、入力完了までは入力欄を切り替えないでください。パレット上のチャンネル表示は入力可能の保証ではなく、実行直前に入力欄を確認します。

未登録の場合は「弾幕を追加・編集」から登録します。共通弾幕は配信者の登録・チャンネル連携なしで使えます。

## 配信者の選び方

パレット上部で「自動判別」または「手動選択」を選びます。変更はすぐに保存されます。

| モード | 入力に使う配信者 |
|---|---|
| 自動判別 | 表示中の動画のチャンネルに連携した配信者 |
| 手動選択 | パレット上部で選んだ配信者 |

自動判別でチャンネル未連携・取得失敗の場合は、配信者別弾幕を入力しません。共通弾幕は利用できます。管理画面で編集対象を変えても、パレットの入力対象は変わりません。入力対象の配信者を削除すると未選択になり、別の配信者を自動で代用しません。

「配信者」はアプリ内の管理単位です。表示名を変更してもYouTube上の名前は変わりません。

## 弾幕と配信者を管理する

パレットの「弾幕を追加・編集」、または「管理・ヘルプ」→「弾幕・配信者を管理」を開きます。「弾幕・配信者」タブの上部で「共通の弾幕」または配信者を選びます。

「パレットへ戻る」は今回のリアクション設定を保ったまま戻ります。変更・失敗の通知は下部に表示し、狭い幅では戻るボタンの上に配置します。長い通知はスクロールして全文を読み、選択・コピーできます。

- **追加・編集**：弾幕名、1行の本文、キーの割当を指定して保存します。ダブルクリックも編集です。キャンセルでは保存しません。
- **複製**：コピーを追加します。キーは割り当てません。
- **上へ・下へ**：表示順を変えます。キーの割当は変わりません。
- **削除**：選んだ弾幕を削除します。削除した弾幕のキーは空きになります。
- **別の対象へ移動…**：弾幕名と移動元を確認し、移動元以外から移動先を選びます。元の一覧からなくなり、キーの割当は解除します。移動先がなければ、先に配信者を追加してください。

配信者は「配信者を追加」で作成します。配信者を選び「配信者の設定…」を開くと、名前変更・チャンネル連携・解除・削除が使えます。配信者の削除は、その配信者の弾幕も削除するため確認画面を表示します。初期設定や最後の配信者を削除した後にサンプルは作りません。

### チャンネル連携

1. YouTubeの動画を開き、入力欄をクリックしてCtrl＋Alt＋Qを押します。
2. パレットの「チャンネル連携…」を押します。
3. このチャンネルで使う配信者を選びます。新しく登録する場合は、アプリ内で表示する名前を入力します。
4. 対象の配信者と「現在」「変更後」のチャンネルを確認し、「連携する」を押します。

同じチャンネルを複数の配信者には連携できません。確定前にチャンネルを再確認し、変わっていたら保存しません。新しい配信者の登録と連携は1回の変更として保存し、1回の取り消しで戻せます。管理画面から既存の配信者を選び、チャンネル連携を変更・解除することもできます。

### キーの割当

| キー | 割当先 |
|---|---|
| Ctrl＋Alt＋1／2 | 入力対象の配信者の弾幕 |
| Ctrl＋Alt＋3／4 | 共通弾幕 |
| Ctrl＋Alt＋Q | パレット。リアクション実行中は進捗表示 |
| Ctrl＋Alt＋R（変更可） | 保存した標準設定でリアクションを実行 |

弾幕の編集画面で割当を選びます。選択肢には現在の割当名を表示します。別の弾幕が使うキーを選ぶと、保存時にその割当を解除して移すことを表示します。並べ替えでは割当は変わりません。割当のないキーでは入力しません。弾幕・リアクションのキーは対象ブラウザーが最前面のときに有効です。

### 保存と取り消し

弾幕・配信者の変更は、操作を確定した時点で保存されます。下部の取り消しボタンは「『拍手』の削除を取り消す」のように対象を表示します。追加・編集・複製・並べ替え・移動・削除・配信者の変更を、直近30件まで順に取り消せます。

履歴は管理画面を閉じても保持しますが、アプリ終了で消えます。リアクションの標準設定や入力対象の選択は巻き戻しません。保存に失敗した場合は変更前のデータと履歴を保持し、弾幕の編集中なら入力内容も保持します。

## リアクションを使う

リアクションはボタン操作まで実行します。**種類・回数・処理間隔・キーは全チャンネル共通です。配信者別の設定はありません。**

### 初回の準備

1. 対象のYouTubeライブからパレットを開きます。
2. 「管理・ヘルプ」→「操作・サポート」を開きます。
3. 「① ボタンを設定…」を押し、YouTubeに戻ったら♡にマウスを重ねて5種類のメニューを表示します。
4. 登録完了を確認します。Escで中止できます。
5. 同じ画面の「② 送らずに確認」を押し、5秒以内にメニューを表示すると、送信せずに検出を確認できます。

登録はブラウザーごとです。正常に検出できる場合は再登録不要です。

画面の「設定済み」は、対象ブラウザーのボタン情報が保存されているという意味です。現在のメニューを認識できる保証ではないため、「② 送らずに確認」で確かめてください。この状態照会は、直前の実操作についての診断情報を上書きしません。

### 今回のリアクションと標準設定

パレット下部で種類・回数・間隔を選び、「リアクションを開始（3秒後）」を押します。YouTubeへ戻って♡のメニューを表示します。ここでの変更は今回のリアクション用です。

- 「標準設定に保存」：今回の値を全チャンネル共通の標準設定として保存します。
- 「標準設定を読み込む」：パレットの今回の値を保存済みの標準設定に戻します。
- ショートカット実行：パレットの今回の値ではなく、保存済みの標準設定を使います。

管理画面の「リアクション」タブでも標準設定を変更できます。パレットの今回の値は自動変更しません。「パレットへ読み込んで戻る」で明示的に反映できます。選択した時点で保存し、保存失敗時は元の選択へ戻します。開始済みの実行条件は途中で変わりません。

| 項目 | 選択肢 |
|---|---|
| 種類 | ハート、笑顔、お祝い、驚き、100点、ランダム（毎回） |
| 回数 | 1、10、100、1000、10000回 |
| 処理間隔 | 待機なし、25、50、100、150、200、250、500、1000ms |

処理間隔は処理開始どうしの目標間隔です。処理時間を含むため、処理が長ければ指定を超えます。待機なしは追加待機なしで、前の処理完了後に次へ進みます。並列実行や、遅れを取り戻すまとめ送りはしません。OSの待機精度によっても指定を超える場合があります。

実行中は**Escまたは進捗表示の「停止」**で止めます。現在の操作の結果確認に時間がかかる場合があります。Ctrl＋Alt＋Qはフォーカスを奪わず進捗を表示します。完了表示は4秒後に消え、「管理・ヘルプ」→「リアクションの実行結果」で再確認できます。「操作済み」はボタン操作の完了数で、YouTubeの受理回数を保証しません。結果不明の操作を自動再送しません。

### リアクションキーの変更

管理画面の「操作・サポート」→「リアクションキーを変更…」を開きます。欄を選び、Ctrl＋AltまたはCtrl＋Shiftと英数字・F1～F12を押して「保存」します。パレット・弾幕と競合するキーは拒否します。「Ctrl＋Alt＋Rを入力」はCtrl＋Alt＋Rを選び直し、「保存」で確定します。

ランダムは1回の操作ごとに5種類から等確率で選びます。同じ種類が続く場合もあります。パレットとキー実行の両方で使えます。

## 初期設定と画面の終了

配信者・弾幕は0件、自動判別はON。リアクションはハート・1回・200ms・Ctrl＋Alt＋Rです。配信者別のリアクション設定は作成しません。

×は画面だけを閉じます。リアクション実行中のEscは処理停止、それ以外は画面を閉じる操作です。アプリの終了は「管理・ヘルプ」→「終了」、またはタスクトレイの「Exit」です。

診断情報は「管理・ヘルプ」または管理画面の「操作・サポート」から開きます。表示時点の情報を手動更新・コピーできます。診断情報のコピーには弾幕本文・動画URL・配信者名・保存先パスを含めません。「リアクションの実行結果」は「結果」と「調査用の詳細」に分かれます。診断情報とは別の情報で、検出したボタン名やエラーメッセージを含むため、共有前に内容を確認してください。

## 画面の表示と移動

パレット上部の「弾幕の入力対象」と、管理画面の「編集する弾幕」は独立しています。自動判別で一致する配信者がない場合は「共通の弾幕のみ」と表示します。

主画面は幅と高さに合わせて配置を調整します。内容の表示に必要な領域はパレット360×620、管理画面360×520を基準とし、それより小さいウィンドウではスクロールして操作できます。Tab／Shift＋Tabで移動した操作部が画面外にあれば、その位置へ自動的にスクロールします。診断画面も必要に応じてスクロールできます。

「操作・サポート」は「キー操作」「リアクションの準備」「使い方・トラブルの確認」の3枠です。「使い方」は弾幕の入力・管理・リアクションの目的別に切り替えられます。ヘルプ・診断・結果画面からCtrl＋Alt＋Qでパレットへ戻っても、対象ブラウザーは保持します。

弾幕入力の案内、標準設定の保存結果、リアクションの結果は、それぞれの操作欄の近くに表示します。進捗の画面更新は最大100msごとにまとめますが、操作回数は毎回記録し、終了結果はすぐに表示します。これはリアクションの処理間隔とは別の設定です。
