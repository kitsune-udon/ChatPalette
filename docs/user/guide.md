# 利用ガイド

[READMEへ戻る](../../README.md) · [困ったとき](maintenance.md)

## 1. 目的に合うタブを選ぶ

| タブ | 用途 |
|---|---|
| ホーム | 弾幕の入力、リアクションの実行、結果の確認 |
| 弾幕ライブラリ | 投稿者別・共通の弾幕を追加、編集、並べ替え |
| 投稿者別設定 | 投稿者ごとのリアクション種類を指定 |
| 共通設定 | リアクションの既定種類、回数、待ち時間、キーを指定 |
| 環境・登録 | 自動判別の切り替え、リアクションボタンの登録・確認 |

「投稿者」はこのツール内の管理単位です。表示名を変えてもYouTube上のチャンネル名は変わりません。

## 2. 共通弾幕を登録する

拍手など、多くのチャンネルで使う文字列を登録します。投稿者の作成や関連付けは不要です。

1. 「弾幕ライブラリ」で「共通の弾幕」を選びます。
2. 「追加」を押し、弾幕名と1行の入力文字列を入力して保存します。
3. YouTubeのチャット入力欄をクリックします。
4. Ctrl＋Alt＋3で1番目、Ctrl＋Alt＋4で2番目を入力します。
5. 入力内容を確認し、YouTube側で送信します。

3件目以降はホームまたは一覧から選んで入力できます。ショートカットは項目の名前ではなく順番に対応するため、並べ替えると入力対象も変わります。

## 3. 投稿者別の弾幕を登録する

1. 「投稿者別設定」または「弾幕ライブラリ」の「投稿者・チャンネル管理」を開きます。
2. 「投稿者を追加」で管理用の名前を登録します。
3. 「弾幕を追加する…」から、弾幕名と入力文字列を保存します。
4. 自動判別を使う場合は、次の手順でチャンネルを関連付けます。

Ctrl＋Alt＋1・2は、その投稿者の弾幕一覧の先頭2件に対応します。チャンネル固有の絵文字コードは、利用するチャンネルで使える文字列を登録してください。

### チャンネルを関連付ける

1. 関連付けたいチャンネルのYouTube動画を開き、Ctrl＋Alt＋Qを押します。
2. 「投稿者・チャンネル管理」で登録済みの投稿者を選びます。
3. 「再検出」を押し、候補の投稿者名とチャンネルを確認します。
4. 「関連付ける」を押します。

名前の一致で関連付ける仕組みではありません。動画から取得したチャンネル情報と、保存した関連付けを照合します。同じチャンネルを複数の投稿者へ関連付けることはできません。

検出候補と実際の動画が変わった場合は、関連付けを確定せず再検出を求めます。

### 手動で使う

「環境・登録」で自動判別をOFFにし、使いたい投稿者を選びます。選択した投稿者の弾幕を使用します。自動判別ONのまま未関連付けの動画で投稿者別弾幕を実行すると、入力を停止します。

投稿者別のリアクション設定に未保存の変更がある間は、投稿者を切り替えられません。共通設定の未保存変更は切り替え後も保持します。

## 4. 弾幕を整理する

一覧の項目を選んで「編集」「複製」「↑ 上へ」「↓ 下へ」「削除」を使います。ダブルクリックでも編集できます。

「共通へ移す」「投稿者別へ移す」はコピーではなく移動です。元の一覧から項目がなくなります。投稿者別へ移すには投稿者の登録が必要です。

「直前の操作を戻す」は履歴一覧ではありません。対象になる直前の操作があるときだけ有効になります。投稿者管理側の「直前の変更を戻す」とは別の機能です。投稿者管理の取り消しは、その管理画面を閉じるまで利用できます。

最後の投稿者を削除すると投稿者は0件になります。共通弾幕は残り、代替のサンプル投稿者は作成しません。

## 5. リアクションを使う

弾幕の文字列入力とは異なり、YouTubeのリアクションボタンを直接操作します。

### 初回のボタン登録

1. リアクションメニューが使えるYouTubeライブを開き、Ctrl＋Alt＋Qを押します。
2. 「環境・登録」→「操作ボタンを登録・再登録」を押します。
3. YouTubeに戻ったら♡にマウスを重ね、5種類のメニューを開きます。
4. メニュー上にマウスを置いたまま、登録完了の表示を待ちます。
5. 「送信せずに検出を確認」を押し、5秒以内に同じメニューを開きます。

登録と検出確認ではリアクションを送りません。登録はブラウザーごとに保存されます。正常に検出できる間は、動画ごとの再登録は不要です。途中でやめる場合はEscを押します。

### 種類・回数・待ち時間を決める

「共通設定」で値を選び、「共通設定を保存」を押します。

| 設定 | 選択肢 | 初期値 |
|---|---|---|
| 種類 | ハート・笑顔・お祝い・驚き・100点 | ハート |
| 回数 | 1・10・100・1000・10000回 | 1回 |
| 操作後の待ち時間 | 25・50・100・200・500・1000ms | 25ms |

待ち時間には検出・操作の所要時間を含みません。25msを選んでも毎秒40回の操作を保証するわけではありません。1回だけ実行する場合、操作間の待ち時間は発生しません。

投稿者ごとに種類を変える場合は、「投稿者別設定」で上書きのチェックを入れ、種類を選んで「この投稿者の設定を保存」を押します。回数・待ち時間・キーは共通設定です。上書きを外すと共通の種類を使います。

自動判別ONでは実行時の動画を基に種類を選びます。関連付け先に上書きがなければ共通の種類を使います。手動モードでは選択中の投稿者の指定を使い、投稿者が0件なら共通の種類を使います。

### ショートカットを変更する

1. 「共通設定」のキー欄をクリックします。
2. Ctrl＋AltまたはCtrl＋Shiftと、英数字キーを同時に押します。
3. すべてのキーを離して「共通設定を保存」を押します。

F1〜F12も指定できます。パネル・弾幕用のCtrl＋Alt＋Q／1／2／3／4は予約済みです。「Ctrl＋Alt＋R に戻す」を押した場合も、保存して確定します。

### 実行・停止・結果確認

- キーで実行：YouTubeを最前面にし、♡メニューを開いた状態でCtrl＋Alt＋Rを押し、キーを離します。
- パネルで実行：ホームの「3秒後に送信を開始」を押し、YouTubeに戻って♡メニューを開きます。
- 停止：Escを押します。処理中の操作がある場合は、その結果を確認してから終了します。
- 進捗表示：実行中にCtrl＋Alt＋Qを押します。
- 結果確認：ホームの「結果の詳細」を開きます。終了後の進捗表示は通常4秒で消えます。

動画や操作先が変わった場合、検出に失敗した場合、結果が不明な場合は停止します。結果不明の操作を自動再送しません。「操作済み」はボタン操作の完了数であり、YouTube側の受理数ではありません。

## 6. 保存と「変更を戻す」の範囲

| 操作場所 | 保存のタイミング | 戻す対象 |
|---|---|---|
| 弾幕ライブラリ | 編集画面の保存、削除・移動等の実行時 | 対象となる直前の弾幕操作 |
| 投稿者・チャンネル管理 | 追加・変更・関連付け等の実行時 | 管理画面内の直前の変更 |
| 投稿者別設定 | 「この投稿者の設定を保存」 | その投稿者の未保存の種類指定 |
| 共通設定 | 「共通設定を保存」 | 共通リアクション設定の未保存変更 |
| 自動判別ON/OFF | 切り替え時 | 専用の取り消しなし。再度切り替える |

パネルを閉じる操作は保存ボタンの代わりにはなりません。リアクション設定に未保存変更がある間は、送信を開始できません。
