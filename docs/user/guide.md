# 弾幕と配信者

[はじめに](../../README.md) · [キー・設定](reference.md)

よく使う1行を弾幕として保存すると、パレットから選んでYouTubeの入力欄に挿入できます。初めて使うときは「共通の弾幕」に1件登録すると、どのチャンネルでも試せます。

## 共通と配信者別を使い分ける

「共通の弾幕」には、拍手などチャンネルを問わず使う本文を登録します。特定の配信者の挨拶などは、その配信者を作成して登録します。パレットには共通の弾幕と、入力対象に選ばれた配信者の弾幕が並びます。

管理画面では、いま編集したい配信者を選べます。別の配信者の弾幕を整理しても、パレットの入力対象はそのままです。

## 弾幕を追加する

1. パレットの「弾幕を追加・編集」を押し、管理画面で「共通の弾幕」か配信者を選びます。配信者を作るには「配信者を追加…」を押します。
2. 「追加…」を押し、一覧で見分けるための「弾幕名」と、YouTubeに入力する「本文（1行）」を書きます。
3. キーでも入力したい場合は「キーの割当」を選びます。パレットから選ぶだけなら「割当なし」のまま「保存」を押します。
4. 「パレットへ戻る」を押します。弾幕が見つからない場合は、パレットの入力対象と検索欄を確認します。

登録済みの弾幕を編集するときは、パレットでその弾幕を選んでから「弾幕を追加・編集」を押すと、対象の行が開きます。どの行も選んでいないときは入力対象の配信者、対象がなければ「共通の弾幕」が開きます。

## 動画に合わせて配信者を自動選択する

1. 連携するチャンネルの動画を開きます。
2. 動画を開いたブラウザーを最前面にし、Ctrl＋Alt＋Qでパレットを開きます。「チャンネル連携…」を押します。
3. 表示されたチャンネルを確認し、「新しい配信者を登録」か登録済みの配信者を選びます。
4. アプリ内で表示する名前と連携先を確認して「連携する」を押します。
5. その配信者の弾幕を追加します。

「自動判別」では、動画のチャンネルと登録した連携先が一致すると、その配信者の弾幕が表示されます。未連携のチャンネルや判別できない動画では、共通の弾幕を使えます。

管理画面からは「配信者の設定…」→「現在のチャンネルと連携…」で同じ画面を開けます。1人の配信者に連携できるのは1チャンネルです。同じチャンネルを複数の配信者に登録することはできません。連携先を変えると、以前のチャンネルではその配信者が自動選択されなくなります。

## チャンネル連携を使わず手動で選ぶ

パレットで「自動判別」を「手動選択」に切り替え、配信者を選びます。動画を変えても自動で切り替わらないため、入力前に対象を確認します。

## 弾幕を入力する

1. YouTubeのチャット・コメント・返信欄をクリックします。
2. Ctrl＋Alt＋Qでパレットを開きます。
3. 弾幕を選び、本文のプレビューを確認します。
4. 「選んだ弾幕を入力」を押します。
5. YouTube側で確認して送信します。

アプリが動画と入力欄を確認し、IMEをオフにしてカーソル位置に挿入します。文字列を選択中なら、その範囲が弾幕に置き換わります。入力後もIMEはオフです。検索欄・アドレス欄や識別できない欄への入力は中止します。処理が終わるまで入力先を切り替えないでください。

タブ・改行・Backspaceなどの制御文字がある場合は本文全体の入力を拒否します。本文を編集して取り除いてください。保存値を自動変更しません。

キーを割り当てた弾幕は、YouTubeの入力欄を選んだまま呼び出せます。チャットへ移動するキー、未送信の内容を消すキー、送信するキーもあります。初期割当と使える欄は[ショートカット一覧](reference.md#ショートカット)を参照してください。

## 編集・整理する

| 管理画面の操作 | 結果 |
|---|---|
| 編集…／ダブルクリック | 名前・本文・キーを変更し、保存で確定 |
| 複製 | キー割当なしのコピーを追加 |
| 削除… | 選んだ弾幕を削除 |
| 上へ／下へ | 順序を変更し、キー割当を維持 |
| 別の対象へ移動… | 元から外して移動し、キー割当を解除 |
| キーの割当… | 選んだ弾幕をキー1かキー2に割り当てる、または割当を解除する |
| 配信者を追加… | 新しい配信者を作成 |
| 配信者の設定… | 名前・連携を変更、配信者を削除 |

配信者を削除すると、その配信者の弾幕も削除されます。パレットで表示順だけを変えたいときは「並べ替え」で保存順、名前・本文、対象、キーの順を選びます。2つのキーに入れる弾幕をまとめて変更するには[弾幕キーの割当手順](reference.md#弾幕キーの内容を選ぶ)を参照してください。

## 保存と取り消し

一覧操作は成功時に自動保存します。編集途中は「保存」まで確定しません。キャンセル・×・Escでは未保存変更の破棄を確認し、「いいえ」で下書きと画面を保持します。

管理画面の「直前の変更を元に戻す」で、弾幕や配信者の編集、弾幕の割当、名前やチャンネル連携の変更を新しい順に取り消せます。履歴は共通と全配信者を合わせて30件までです。同じ値を保存しても履歴は増えません。リアクションの標準設定は対象外です。履歴はアプリ終了時に消去されるため、後日復元するには[バックアップ](maintenance.md#バックアップする)を使います。
