# 操作・設定リファレンス

[文書一覧](../index.md)

## ショートカット

以下は初期割当です。「管理・ヘルプ」またはトレイの「ショートカットを管理」で変更します。

停止以外は通常キーを離したときに1回実行します。Ctrl・Alt・Shiftは押したままで構いません。押しっぱなしでは連発せず、停止だけは押下時に実行します。

| 初期キー | 動作・条件 |
|---|---|
| Ctrl＋Alt＋Q | パレットを開く。リアクション中は進捗。他アプリからも呼べる |
| Ctrl＋Alt＋1／2 | 配信者の割当1／2を入力 |
| Ctrl＋Alt＋3／4 | 共通の割当1／2を入力 |
| Ctrl＋Alt＋F | 一意に識別した、表示中の編集可能なチャット欄へ移動 |
| Ctrl＋Alt＋W | チャットへ移動して未送信内容をクリア。送信しない |
| Ctrl＋Alt＋R | 表示起点へマウスを重ね、リアクションUIを表示。クリック・送信しない |
| Ctrl＋Alt＋T | 保存した標準設定でリアクションを実行 |
| Ctrl＋Alt＋E | 現在のチャット欄を確認し、Enterを1回送って送信 |
| Esc | 実行・待機中のリアクションと後続操作を停止 |

ブラウザー操作はYouTubeが最前面で、対象を識別できることが必要です。弾幕キーは入力だけを行います。クリア・送信はコメント・検索欄を対象にせず、YouTube側の受理は確認しません。

### キーを変更する

1. 操作を選び、Ctrl＋AltまたはCtrl＋Shiftを含む英字・数字・F1〜F12を押します。入替時はすべて変更します。
2. 重複を解消し、「キー設定を保存」を押します。

保存と実行時登録をまとめて反映し、失敗時は保存せずキーを戻します。復旧に失敗した案内が出たら再起動します。

パレット・リアクション実行・停止以外は「割当を解除」で無効にできます。停止は「停止をEscに」も使えます。画面を閉じるEscとは別の設定です。「標準の割当に戻す」は保存するまで反映しません。

### 弾幕キーの内容を選ぶ

1. 下段「弾幕キーで入力する内容」で共通か配信者を選びます。入力対象は変わりません。
2. 2つの欄で弾幕か「未割当」を選びます。
3. 「弾幕の割当を保存」を押します。

キー設定と弾幕割当は別の保存です。一方を保存しても他方の下書きは残ります。同じ弾幕を両方へ指定できず、2つの入替は可能です。

弾幕編集で割当1／2を指定すると、保存時に以前の弾幕から付け替えます。保存前に案内します。割当は並べ替えても維持します。未保存変更の破棄や対象切替は確認します。すべての弾幕入力はIMEをオフにし、そのまま保持します。

### ショートカットを続けて入力する

通常キーを離した順に一つずつ実行します。修飾キーを押したまま、フォーカス→弾幕→送信などを続けて入力できます。同じキーの繰返しも保持します。クリア・リアクション・パレット表示も同じキューで待機し、5秒の期限はありません。

停止、操作失敗、対象ウィンドウ・動画の変更は後続を破棄します。動画は進行中の確認済み動画、なければ最初の実行で確認した動画へ固定します。弾幕は受付時の割当を使い、入力直前に同じID・本文・対象か確認します。

送信は現在のチャットへEnterを1回送ります。自動で欄を移動せず、結果不明でも再送しません。

### ページ操作の条件

フォーカス移動は一度行い、反映を最大350ms待ちます。入力欄なし・複数・移動未確認では理由を表示して中止します。クリアは移動先と同じ要素か直前に確認します。

チャットを表示し、アドレス欄の編集を終えてください。識別不能や編集中は拒否します。通信・リアクション中のキーはキューで待ちます。必要なUI情報が取得できなければ、手動で入力欄をクリックするか♡へ重ねます。確認と入力は不可分ではないため、処理中に対象を切り替えないでください。

弾幕・配信者は0件、入力対象は自動判別、リアクションはハート・1回・200ms、ボタンは未登録です。サンプルは作りません。更新時に既存設定を初期値で上書きしません。

## リアクションの選択肢

| 項目 | 値 |
|---|---|
| 種類 | ハート・笑顔・お祝い・驚き・100点・ランダム（毎回） |
| 回数 | 1・10・100・1000・10000回 |
| 間隔 | 待機なし・25・50・100・150・200・250・500・1000ms |

[間隔と回数の意味](reactions.md#間隔と回数の読み方)を確認してください。

## 保存されるもの

`main.ahk`と同じ階層の`data/settings.db`へ保存し、なければ作成します。

| 情報 | 確定・保持 |
|---|---|
| 弾幕・配信者・連携・弾幕割当 | 編集保存、一覧操作、連携成功時にDBへ保存 |
| 自動／手動・入力配信者 | 変更成功時に保存。自動判別の切替も含む |
| 標準リアクション・キー | 管理画面の変更、キー保存、「標準設定に保存」で保存 |
| ブラウザー別ボタン登録 | 検出後の保存確定時 |
| 今回の条件・検索・編集対象・Undo | メモリのみ。終了で失う。Undoは直近30件 |
| 動画情報・ボタン検出キャッシュ | メモリのみ。ワーカー再起動で失う |

付随するジャーナル・WAL・共有メモリを単独で削除せず、[保守手順](maintenance.md)を使います。

## 上限

配信者10000件、弾幕合計100000件、保存計画で数える文字列合計32MiB（UTF-16）、DB本体128MiBです。保存制限で、快適な操作を保証する件数ではありません。JSONの上限も128MiBです。

## 終了の違い

パレット・管理・診断の×は画面を隠して常駐を続けます。弾幕編集・キー管理は未保存変更の破棄を確認し、「いいえ」で編集へ戻ります。画面を閉じてもリアクション停止にはなりません。停止キーか停止ボタンを使います。

アプリ全体は「管理・ヘルプ」またはトレイの「終了」で終了します。

## ネットワークと個人情報

自動判別では必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。オフライン・取得失敗では判別できない場合があります。動画キャッシュはファイルへ保存しません。

DBには弾幕・配信者名・連携を含みます。共有にはDB全体ではなく[診断コピー](maintenance.md#調査を依頼する)を使います。

## 大量の弾幕の表示

パレットは検索結果の先頭500件を表示し、超過時は絞り込みを案内します。検索は全件が対象です。管理一覧と保存件数の上限は変わりません。
