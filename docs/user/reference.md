# 操作・設定リファレンス

[はじめに](../../README.md)

## ショートカット

以下は初期割当です。現在の割当は、パレットの「管理・ヘルプ」または通知領域のChatPaletteアイコンのメニューから「ショートカットを管理…」を開くと確認できます。

停止以外は通常キーを離したときに1回実行します。Ctrl・Alt・Shiftは押したままで構いません。押しっぱなしでは連発せず、停止だけは押下時に実行します。

| 初期キー | 動作・条件 |
|---|---|
| Ctrl＋Alt＋Q | パレットを開く。リアクション中は進捗。他アプリからも呼べる |
| Ctrl＋Alt＋1／2 | 配信者の割当1／2を入力 |
| Ctrl＋Alt＋3／4 | 共通の割当1／2を入力 |
| Ctrl＋Alt＋F | 一意に識別した、表示中の編集可能なチャット欄へ移動 |
| Ctrl＋Alt＋W | チャットへ移動して未送信内容をクリア。送信しない |
| Ctrl＋Alt＋R | ♡にマウスを重ね、リアクションメニューを表示。送信はしない |
| Ctrl＋Alt＋T | 保存した標準設定でリアクションを実行 |
| Ctrl＋Alt＋E | 現在のチャット欄を確認し、Enterを1回送って送信 |
| Esc | 実行中・待機中の操作と、待っている後続のショートカットを停止 |

ブラウザー操作はYouTubeが最前面で、対象を識別できることが必要です。弾幕キーは入力だけを行います。クリア・送信はコメント・検索欄を対象にせず、YouTube側の受理は確認しません。

### キーを変更する

1. 「ショートカットを管理…」で、変更したい操作の入力欄を選びます。
2. Ctrl＋AltまたはCtrl＋Shiftを押しながら、英字、数字、F1〜F12のいずれかを押します。「停止」ではEscもそのまま入力できます。
3. 2つの操作のキーを交換するときは両方の欄を変更します。「重複」が解消したら「キー設定を保存」を押します。保存した割当はすぐに使えます。

使わない操作は入力欄を空にして保存すると割当を解除できます。「パレットを開く」「リアクションを実行」「停止」の3つは割当が必要です。「標準の割当に戻す」で初期割当が欄に入り、「キー設定を保存」で確定します。

保存に失敗したときは以前の割当で操作できます。欄の表示とエラーを確認し、原因を解消して保存し直してください。

### 弾幕キーの内容を選ぶ

1. 「ショートカットを管理…」の下段「弾幕キーで入力する内容」で「共通の弾幕」か配信者を選びます。ここでの選択はパレットの入力対象に影響しません。
2. 枠1・枠2に入れたい弾幕を選びます。空けておく枠は「未割当」を選びます。
3. 「弾幕の割当を保存」を押します。

キー設定と弾幕割当は別の保存です。一方を保存しても他方の下書きは残ります。同じ弾幕を両方へ指定できず、2つの入替は可能です。

弾幕編集で割当1／2を指定すると、保存時に以前の弾幕から付け替えます。保存前に案内します。割当は並べ替えても維持します。未保存変更の破棄や対象切替は確認します。すべての弾幕入力はIMEをオフにし、そのまま保持します。

### ショートカットを続けて入力する

たとえば初期割当で、CtrlとAltを押したまま、F、3、Eを順に1回ずつ押して離すと、チャット欄への移動、共通の枠1の弾幕入力、送信の順に進みます。先に枠1へ弾幕を割り当ててください。同じキーの繰り返しも離した順に受け付けます。クリア・リアクション・パレット表示も順番を待ちます。

停止したとき、途中の操作に失敗したとき、ウィンドウや動画が変わったときは後続の操作も取り消します。一連の操作では最初に確認した動画を使い、弾幕を入力する直前には、キーを押したときと同じ弾幕・本文・配信者が選ばれているかを確かめます。

送信は現在のチャットへEnterを1回送ります。自動で欄を移動せず、結果不明でも再送しません。

### ページ操作の条件

フォーカス移動は一度行い、反映を最大350ms待ちます。入力欄なし・複数・移動未確認では理由を表示して中止します。クリアは移動先と同じ要素か直前に確認します。

チャットを表示し、アドレス欄の編集を終えてください。識別不能や編集中は拒否します。通信・リアクション中のキーはキューで待ちます。必要なUI情報が取得できなければ、手動で入力欄をクリックするか♡へ重ねます。確認と入力は不可分ではないため、処理中に対象を切り替えないでください。

## 初期状態

初回起動時の弾幕・配信者は0件で、入力対象は「自動判別」です。リアクションの標準設定はハート・1回・200 msで、ボタンは未登録です。更新時に既存の設定を引き継ぐ方法は[更新手順](maintenance.md#更新を反映する)を参照してください。

## リアクションの選択肢

| 項目 | 値 |
|---|---|
| 種類 | ハート・笑顔・お祝い・驚き・100点・ランダム（毎回） |
| 回数 | 1・10・100・1000・10000回 |

[間隔と回数の意味](reactions.md#間隔と回数の読み方)を確認してください。

## 保存されるもの

`ChatPalette.exe` と同じ階層の `data/settings.db` へ保存し、なければ作成します。

| 情報 | 確定・保持 |
|---|---|
| 弾幕・配信者・連携・弾幕割当 | 編集保存、一覧操作、連携成功時にDBへ保存 |
| 自動／手動・入力配信者 | 変更成功時に保存。自動判別の切替も含む |
| リアクションの標準設定 | パレットの「標準設定に保存」で保存 |
| 操作に使うショートカット | 「ショートカットを管理…」の「キー設定を保存」で保存 |
| ブラウザー別ボタン登録 | 検出後の保存確定時 |
| 今回の条件・検索・編集対象・Undo | メモリのみ。終了で失う。Undoは直近30件 |
| 動画情報・ボタン検出キャッシュ | メモリのみ。ワーカー再起動で失う |

付随するジャーナル・WAL・共有メモリを単独で削除せず、[保守手順](maintenance.md)を使います。

## 上限

配信者は1万件、共通と配信者別を合わせた弾幕は10万件まで保存できます。保存時に数える文字列の合計はUTF-16換算で32 MiB、DB本体と入出力するJSONはそれぞれ128 MiBが上限です。件数や本文の長さによって、読み込みや表示にかかる時間は変わります。

## 終了の違い

パレット・管理・診断の×は画面を隠して常駐を続けます。弾幕編集・キー管理は未保存変更の破棄を確認し、「いいえ」で編集へ戻ります。画面を閉じてもリアクション停止にはなりません。停止キーか停止ボタンを使います。

アプリ全体は「管理・ヘルプ」またはトレイの「終了」で終了します。

## ネットワークと個人情報

自動判別では必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。オフライン・取得失敗では判別できない場合があります。動画キャッシュはファイルへ保存しません。

DBには弾幕本文や配信者名、連携先が入っています。調査を依頼するときは[診断情報をコピーする手順](maintenance.md#調査を依頼する)を参照してください。

## 大量の弾幕の表示

パレットは入力対象の配信者の弾幕、共通の弾幕の順に名前と本文を検索し、一致した先頭500件を表示します。「並べ替え」はこの表示範囲に適用されます。目的の弾幕が見つからないときは検索語を追加するか、入力対象の配信者を確認してください。管理画面では選んだ対象の弾幕を全件確認できます。
