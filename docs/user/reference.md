# 操作・設定リファレンス

[文書一覧](../index.md)

## ショートカット

以下は初期割当です。すべての操作キーを管理画面で変更できます。

| キー | 動作 | 条件 |
|---|---|---|
| Ctrl＋Alt＋Q | パレットを開く。リアクション実行中は進捗を表示 | 他アプリからも呼び出せる。YouTubeから呼ぶと対象を引き継ぐ |
| Ctrl＋Alt＋1／2 | 配信者別弾幕の割当1／2を入力 | 対象ブラウザーが最前面。割当済み・入力欄を識別できること |
| Ctrl＋Alt＋3／4 | 共通弾幕の割当1／2を入力 | 同上 |
| Ctrl＋Alt＋F | チャット入力欄へフォーカス | YouTubeの動画ページが最前面。表示中の編集可能なチャット欄を一意に識別できること |
| Ctrl＋Alt＋C | チャット入力欄へ移動し、入力内容をクリア | 同上。コメント欄や検索欄は対象外。送信しない |
| Ctrl＋Alt＋E | ページ内のリアクションUIを表示 | 表示用UIを識別してマウスを重ねる。クリック・送信しない |
| Ctrl＋Alt＋R | 標準設定でリアクションを実行 | 対象ブラウザーが最前面 |
| Esc | リアクションを停止 | 実行・待機中。編集画面ではキャンセルにも使用 |

「管理・ヘルプ」→「ショートカットを管理」で現在の割当を確認・変更します。「使い方」の下部、管理画面の「操作・サポート」、トレイ、診断情報のボタンも同じショートカット管理画面を開きます。

1. 一覧から操作を選び、入力欄でCtrl＋AltまたはCtrl＋Shiftを含むキーを押します。英字・数字・F1〜F12を使用できます。入力は一覧へ自動反映され、「変更あり」や「重複」を表示します。複数のキーを入れ替える場合も、すべて変更してから保存します。
2. 「キー設定を保存」で保存と実行時の登録をまとめて反映します。重複は拒否し、失敗した変更は保存せず、実行時の割当を元に戻します。キーを元に戻せなかった旨が表示された場合は、ChatPaletteを再起動して保存済みの割当を読み直してください。

パレット・リアクション実行・停止以外は「割当を解除」で無効化できます。停止は通常の修飾キー付き操作に加え「停止をEscに」でも設定できます。画面を閉じるEsc操作は、リアクション停止キーとは別です。「標準の割当に戻す」は画面上の設定だけを戻し、保存するまで反映しません。

下段では共通・配信者を選び、2つの弾幕キーが入力する内容を指定して「弾幕の割当を保存」します。キー設定と弾幕割当は独立した保存です。キーを保存しても編集中の弾幕選択は保持します。それぞれ変更がある場合だけ保存できます。未保存の変更がある状態で閉じる場合や、弾幕の編集対象を切り替える場合は、破棄するか確認します。対象の選択でパレットの入力配信者は変わりません。

弾幕は入力直前にIMEをオフにし、入力後もオフのままにします。ショートカット・パレット・フォーカス後の保留入力すべてに適用します。

### フォーカスから続けて弾幕を入力する

フォーカスキー（初期値Ctrl＋Alt＋F）の直後に弾幕キーを押せます。フォーカス処理中なら、最初の1件だけを最大5秒保留します。Ctrl・Alt・Shiftを含めて押しているキーをすべて離すと、同じ動画・同じチャット欄・同じ弾幕本文を確認して入力します。

追加の連打は蓄積せず、失敗・対象変更・期限切れでは破棄します。クリアやリアクション操作は保留しません。弾幕は入力までで、Enterによる送信は行いません。

### ページ操作の条件

ページ操作はキーを離した後に実行します。チャット欄へのフォーカス移動は一度だけ行い、反映を最大350ms待って確認します。入力可能な欄がない場合、複数ある場合、移動を確認できない場合は、それぞれ理由を表示して中止します。クリアは、フォーカスしたチャット欄と同じ要素かを直前に確認し、別の欄へ移った場合は削除を中止します。

チャットが閉じている場合は先に表示してください。URL入力中、対象を識別できない場合、編集・通信・リアクションの処理中は実行しません。「リアクションUIを表示」（初期割当Ctrl＋Alt＋E）はマウスポインターを移動するため、メニューを開いたまま使う間はその位置を保ってください。YouTubeやブラウザーが必要なUI情報を公開していない場合は、手動で入力欄をクリック／♡にマウスを重ねてください。

|---|---|

| 入力対象の選び方 | 自動判別 |

サンプルデータは作りません。初期値は新規状態の値で、更新時に既存設定を上書きするものではありません。

## リアクションの選択肢

| 項目 | 選べる値 |
|---|---|
| 種類 | ハート、笑顔、お祝い、驚き、100点、ランダム（毎回） |
| 回数 | 1・10・100・1000・10000回 |
| 間隔 | 待機なし・25・50・100・150・200・250・500・1000ms |

間隔と操作済み回数の意味は[リアクション](reactions.md#間隔と回数の読み方)を参照してください。

## 保存されるもの

保存先は `main.ahk` と同じ階層の `data/settings.db` です。フォルダーとDBがなければ自動作成します。通常の設定ファイルはこのDBに集約されています。

| 情報 | 保存 | 確定するタイミング |
|---|---|---|
| 弾幕・配信者・チャンネル連携・キー割当 | DB | 編集画面の保存、一覧操作や連携の成功時 |
| 自動判別／手動選択・入力配信者 | DB | 変更成功時。自動判別で入力配信者が切り替わる場合も保存 |
| リアクション標準設定・キー | DB | 管理画面での変更、キーの保存、標準設定に保存 |
| ブラウザー別ボタン登録 | DB | 検出後、登録の保存が確定した時点 |
| パレットの今回の条件・検索・編集対象 | メモリ | アプリ終了で失われる |
| 取り消し履歴 | メモリ | 起動中の直近30件。再起動で失われる |
| 動画情報・ボタンの検出結果 | メモリ | ワーカーの再起動で失われる |

DBへの書き込み中や異常終了後は、ジャーナルなどの付随ファイルが存在する場合があります。不要と判断して削除せず、[保守手順](maintenance.md)に従ってください。

## 上限

配信者10000件、弾幕合計100000件、名前・本文等の保存計画で数える文字列合計32MiB（UTF-16換算）、DB本体128MiBが上限です。これは保存時の制限であり、その件数で快適に操作できるという性能保証ではありません。

## 終了の違い

パレット・管理・診断画面の×は画面を隠し、アプリは常駐します。弾幕編集・ショートカット管理では、未保存の変更があるときだけ破棄を確認します。「いいえ」で編集へ戻れます。変更がなければ確認せず閉じます。画面を閉じる操作とリアクションの停止は区別し、停止には設定した停止キー（初期値Esc）または停止ボタンを使ってください。

アプリ全体の終了は、パレットの「管理・ヘルプ」→「終了」、またはタスクトレイの「Exit」です。

## ネットワークと個人情報

動画の配信者を判別するとき、必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。オフラインや取得失敗時は自動判別できない場合があります。取得した動画情報のキャッシュはファイルへ保存しません。

設定DBには自分で登録した弾幕・配信者名・チャンネル連携が含まれます。診断情報を共有する際は、DB全体ではなく[診断コピー](maintenance.md#調査を依頼する)を使用してください。

## 大量の弾幕の表示

パレットは検索結果の先頭500件までを表示します。上限を超えた場合は絞り込みの案内を表示します。検索対象は全件で、表示上限の外にある弾幕も検索できます。管理画面での一覧と保存件数の上限は変わりません。
