# 操作・設定リファレンス

[文書一覧](../index.md)

## ショートカット

| キー | 動作 | 条件 |
|---|---|---|
| Ctrl＋Alt＋Q | パレットを開く。リアクション実行中は進捗を表示 | 他アプリからも呼び出せる。YouTubeから呼ぶと対象を引き継ぐ |
| Ctrl＋Alt＋1／2 | 配信者別弾幕の割当1／2を入力 | 対象ブラウザーが最前面。割当済み・入力欄を識別できること |
| Ctrl＋Alt＋3／4 | 共通弾幕の割当1／2を入力 | 同上 |
| Ctrl＋Alt＋R | 標準設定でリアクションを実行 | 初期値。変更可能。対象ブラウザーが最前面 |
| Esc | 実行中のリアクションを中止／画面の終了操作 | 状況に依存。編集画面では編集をキャンセル |

パレット・弾幕のキーは固定です。リアクションキーはCtrlを含み、さらにAltまたはShiftを含む組み合わせに変更できます。文字は英字・数字・F1〜F12です。Ctrl＋Alt＋Q、Ctrl＋Alt＋1〜4と同じ組み合わせは指定できません。

## 初期状態

| 項目 | 初期値 |
|---|---|
| 配信者・共通弾幕・配信者別弾幕 | すべて0件 |
| 入力対象の選び方 | 自動判別 |
| リアクション | ハート、1回、200ms |
| リアクションキー | Ctrl＋Alt＋R |
| ボタン登録 | 未登録 |

サンプルデータは作りません。初期値は新規状態の値で、更新時に既存設定を上書きするものではありません。

## リアクションの選択肢

| 項目 | 選べる値 |
|---|---|
| 種類 | ハート、笑顔、お祝い、驚き、100点、ランダム（毎回） |
| 回数 | 1・10・100・1000・10000回 |
| 間隔 | 待機なし・25・50・100・150・200・250・500・1000ms |

間隔と操作済み回数の意味は[リアクション](reactions.md#間隔と回数の読み方)を参照してください。

## 保存されるもの

保存先は `main.ahk` と同じ階層の `data/settings.db` です。フォルダーとDBがなければ自動作成します。通常の設定ファイルはこのDBに集約されています。

| 情報 | 保存 | 確定するタイミング |
|---|---|---|
| 弾幕・配信者・チャンネル連携・キー割当 | DB | 編集画面の保存、一覧操作や連携の成功時 |
| 自動判別／手動選択・入力配信者 | DB | 変更成功時。自動判別で入力配信者が切り替わる場合も保存 |
| リアクション標準設定・キー | DB | 管理画面での変更、キーの保存、標準設定に保存 |
| ブラウザー別ボタン登録 | DB | 検出後、登録の保存が確定した時点 |
| パレットの今回の条件・検索・編集対象 | メモリ | アプリ終了で失われる |
| 取り消し履歴 | メモリ | 起動中の直近30件。再起動で失われる |
| 動画情報・ボタンの検出結果 | メモリ | ワーカーの再起動で失われる |

DBへの書き込み中や異常終了後は、ジャーナルなどの付随ファイルが存在する場合があります。不要と判断して削除せず、[保守手順](maintenance.md)に従ってください。

## 上限

配信者10000件、弾幕合計100000件、名前・本文等の保存計画で数える文字列合計32MiB（UTF-16換算）、DB本体128MiBが上限です。これは保存時の制限であり、その件数で快適に操作できるという性能保証ではありません。

## 終了の違い

パレット・管理・診断画面の×は画面を隠し、アプリは常駐します。編集画面の×は未保存の編集をキャンセルします。画面を閉じる操作とリアクションの停止は区別し、停止にはEscまたは停止ボタンを使ってください。

アプリ全体の終了は、パレットの「管理・ヘルプ」→「終了」、またはタスクトレイの「Exit」です。

## ネットワークと個人情報

動画の配信者を判別するとき、必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。オフラインや取得失敗時は自動判別できない場合があります。取得した動画情報のキャッシュはファイルへ保存しません。

設定DBには自分で登録した弾幕・配信者名・チャンネル連携が含まれます。診断情報を共有する際は、DB全体ではなく[診断コピー](maintenance.md#調査を依頼する)を使用してください。
