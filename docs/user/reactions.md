# リアクションを使う

[文書一覧](../index.md) · [選択肢](reference.md#リアクションの選択肢)

リアクションはYouTubeのボタンを操作して送信します。条件は全チャンネル共通です。以下のキーは[現在の割当](reference.md#ショートカット)を使います。

## 初回だけ行うボタンの設定

リアクションメニューを使えるライブ配信で準備します。

1. YouTubeを最前面にしてパレットを開きます。
2. 「管理・ヘルプ」→「操作・サポート」→「① ボタンを設定…」を押します。
3. ♡へマウスを重ねて5種類を表示し、登録が終わるまでその位置を保ちます。中止には停止キーを使います。
4. 「② 送らずに確認」を押し、5秒後の確認までに♡のメニューを開きます。

確認ではボタンを操作しません。「設定済み」は保存済みという意味で、現在のメニュー認識を保証しません。登録はブラウザー種別ごとです。表示変更で認識できなくなったら再登録します。

## パレットから実行する

1. 「今回のリアクション」で種類・回数・間隔を選びます。
2. 「リアクションを開始（3秒後）」を押します。
3. YouTubeへ戻り、3秒以内に♡のメニューを開きます。
4. メニューを表示したまま待ちます。途中で止めるには停止キーか停止ボタンを使います。

実行中にパレットキーを押すと進捗を表示します。終了後は「リアクションの実行結果」を確認します。動画・操作先の変更、メニュー未検出、結果不明では停止します。検査と操作は不可分ではないため、実行中の画面切替を避けてください。

## キーで実行する

1. YouTubeを最前面にし、「リアクションUIを表示」のキーで♡へマウスを移します。識別できなければ手動で重ねます。この操作は送信・登録を行いません。
2. 5種類を表示してから「リアクションを実行」のキーを押し、離します。

キー実行は保存した標準設定を使い、3秒の待機はありません。

## 今回の条件と標準設定

| 操作 | 結果 |
|---|---|
| パレットで条件を選ぶ | 今回だけ。通常の画面往復では維持し、アプリ終了で失う |
| 「標準設定に保存」 | 今回の条件を保存し、以後のキー実行に使う |
| 「標準設定を読み込む」 | 今回の条件を保存値へ戻す |
| 管理画面の「リアクション」で選ぶ | 標準設定を即時保存。現在のパレット条件は変えない |
| 「パレットへ読み込んで戻る」 | 標準設定を今回の条件へ反映 |

起動時の今回の条件は標準設定から読み込みます。

## 間隔と回数の読み方

間隔は処理開始から次の開始までの目標時間です。200ms指定で処理に25msかかれば約175ms待ちます。処理が240msなら追加待機を省き、並列送信で遅れを取り戻しません。「待機なし」も処理終了を待ちます。

平均開始間隔は成功した処理の開始時刻から算出します。YouTubeの受理間隔ではありません。ランダムは毎回5種類から選ぶため、同じ種類が続く場合もあります。

「操作済み」はボタン操作の完了数です。YouTube側の受理数は確認せず、結果不明の操作を再送しません。

## 中止が確定するタイミング

停止しても、既に依頼したボタン操作は取り消せない場合があります。現在の結果を確認して終了します。

登録の保存前に中止すると以前の登録を維持します。保存後の中止は確定値を取り消しません。同期失敗でもDBの登録を残し、次の操作で再同期します。[失敗時の対処](maintenance.md#症状から確認する)を参照してください。
