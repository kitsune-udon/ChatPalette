# リアクションを使う

[はじめに](../../README.md) · [選択肢](reference.md#リアクションの選択肢)

使うブラウザーで初めて実行する場合は、[ボタンを設定して送らずに確認](#初回だけ行うボタンの設定)します。

| やりたいこと | 手順 |
|---|---|
| 今回の種類・回数・間隔を選んで送る | [パレットから実行する](#パレットから実行する) |
| 保存済みの標準設定ですぐに送る | [キーで実行する](#キーで実行する) |
| 実行を止め、どこまで操作されたか確かめる | [中止が確定するタイミング](#中止が確定するタイミング) |

## 初回だけ行うボタンの設定

使いたいブラウザーで、リアクションメニューのあるYouTubeライブ配信を開きます。

1. ブラウザーを最前面にし、Ctrl＋Alt＋Qでパレットを開きます。
2. 「管理・ヘルプ」→「① ボタンを設定…」を選びます。YouTubeに戻ったら♡にマウスを重ね、5種類を表示します。
3. 開いたメニューにマウスを重ねたまま、進捗画面に登録完了が表示されるまで待ちます。途中でやめるときは停止キー（初期割当はEsc）を押します。
4. 同じブラウザーからパレットを開き直し、「管理・ヘルプ」→「② 送らずに確認」を選びます。5秒以内に♡のメニューを開き、5種類を確認できたことが進捗画面に表示されるまで待ちます。

「設定済み」は、そのブラウザー用の登録を保存できたことを示します。YouTubeの表示が変わって確認に失敗したときは、同じブラウザーで登録からやり直してください。

## パレットから実行する

1. 「今回のリアクション」で種類・回数・間隔を選びます。
2. 「リアクションを開始（3秒後）」を押します。
3. YouTubeへ戻り、3秒以内に♡のメニューを開きます。
4. メニューを表示したまま待ちます。途中で止めるには停止キーか停止ボタンを使います。

実行中にパレットキーを押すと、操作先のブラウザーと同じモニターに進捗画面が表示されます。動画や操作先が変わったとき、メニューを見つけられないとき、操作の結果が分からないときは停止します。実行中は同じ動画とメニューを表示したままにしてください。終了後、結果が表示されている間も、その下にあるブラウザーを操作できます。詳細は「管理・ヘルプ」→「リアクションの実行結果」で確認できます。

## キーで実行する

1. YouTubeを最前面にし、Ctrl＋Alt＋R（「リアクションUIを表示」）で♡へマウスを移します。5種類が表示されなければ手動で♡に重ねます。この段階では送信しません。
2. 5種類が見えている状態でCtrl＋Alt＋T（「リアクションを実行」）を押し、Tを離します。保存した標準設定ですぐに実行が始まります。

記載したキーは初期割当です。変更したキーは「ショートカットを管理…」で確認できます。[ショートカット一覧](reference.md#ショートカット)

## 今回の条件と標準設定

| 操作 | 結果 |
|---|---|
| パレットで条件を選ぶ | 今回だけ。通常の画面往復では維持し、アプリ終了で失う |
| 「標準設定に保存」 | 今回の条件を保存し、以後のキー実行に使う |
| 「標準設定を読み込む」 | 今回の条件を保存値へ戻す |
| 管理画面の「標準設定を読み込んで戻る」 | 標準設定を今回の条件へ反映し、パレットを表示 |

標準設定は全チャンネルで共通です。起動時の今回の条件は標準設定から読み込みます。

## 間隔と回数の読み方

間隔は処理開始から次の開始までの目標時間です。200ms指定で処理に25msかかれば約175ms待ちます。処理が240msなら追加待機を省き、並列送信で遅れを取り戻しません。「待機なし」も処理終了を待ちます。

平均開始間隔は成功した処理の開始時刻から算出します。YouTubeの受理間隔ではありません。ランダムは毎回5種類から選ぶため、同じ種類が続く場合もあります。

「操作済み」はボタン操作の完了数です。YouTube側の受理数は確認せず、結果不明の操作を再送しません。

## 中止が確定するタイミング

停止キーか進捗画面の「停止」を押すと、後続の操作を打ち切ります。すでに始まったボタン操作は完了する場合があります。進捗画面で最後の「操作済み」回数を確認してください。

登録の保存前に中止すると以前の登録を維持します。保存後の中止は確定値を取り消しません。同期失敗でもDBの登録を残し、次の操作で再同期します。[失敗時の対処](maintenance.md#症状から確認する)を参照してください。
