# リアクションを使う

[文書一覧](../index.md) · [種類・回数・間隔の一覧](reference.md#リアクションの選択肢)

リアクションはYouTubeのボタン操作まで実行します。弾幕の入力補助とは異なり、実行後に手動で送信ボタンを押す手順はありません。設定は全チャンネル共通です。

## 初回だけ行うボタンの設定

リアクションメニューを表示できるライブ配信で準備します。

1. YouTubeを最前面にしてCtrl＋Alt＋Qを押します。
2. 「管理・ヘルプ」→「操作・サポート」を開きます。
3. 「① ボタンを設定…」を押し、YouTubeの♡にマウスを重ねて5種類のメニューを表示します。
4. 登録結果を確認します。識別できるまでの待機中は、メニュー上にマウスを置いたままにします。中止する場合はEscを押します。
5. 同じ画面の「② 送らずに確認」を押し、開始までに♡のメニューを開きます。確認は5秒後に行います。

「② 送らずに確認」はボタンを操作しません。「設定済み」は登録情報が保存されているという意味であり、現在のメニューを認識できたという保証ではありません。

登録はブラウザーの種類ごとに保存され、配信者ごとには行いません。ブラウザーやYouTubeの表示が変わり認識できなくなった場合は再登録します。スクリーンショットの撮影は不要です。

## パレットから実行する

1. 「今回のリアクション」で種類・回数・間隔を選びます。
2. 「リアクションを開始（3秒後）」を押します。
3. YouTubeに戻り、3秒以内に♡へマウスを重ねてメニューを表示します。
4. メニューを表示したまま結果を待ちます。途中で止める場合はEsc、または表示中の停止ボタンを使います。

実行中にCtrl＋Alt＋Qを押すと進捗を表示します。終了後の情報は「管理・ヘルプ」→「リアクションの実行結果」で確認できます。

動画や操作先が変わった場合、メニューが見つからない場合、結果を確認できない場合は停止します。操作直前にも最前面を確認しますが、確認とボタン操作は不可分な処理ではありません。実行中の画面切り替えは避けてください。

## キーで実行する

YouTubeを最前面にし、♡のメニューを開いてリアクションキーを押します。初期値はCtrl＋Alt＋Rです。キーを離すと、保存された**標準設定**で実行します。パレットの3秒カウントダウンとは異なるため、先にメニューを表示してください。

キーの変更は「操作・サポート」→「リアクションのキーを変更…」で行います。入力欄を選び、使いたいキーの組み合わせを押して保存します。[使用できる組み合わせ](reference.md#ショートカット)には制約があります。

## 今回の条件と標準設定

| 操作 | 変わるもの |
|---|---|
| パレットで種類・回数・間隔を選ぶ | 今回の条件。アプリを終了すると保持しない |
| パレットの「標準設定に保存」 | 今回の条件を保存し、以後のキー実行に使う |
| パレットの「標準設定を読み込む」 | 今回の条件を保存済みの標準設定へ戻す |
| 管理画面の「リアクション」で選択する | 標準設定を即時保存。現在のパレットの条件は変えない |
| 「パレットへ読み込んで戻る」 | 標準設定を今回の条件へ反映してパレットへ戻る |

パレットの条件は通常の画面往復では維持され、アプリ起動時に標準設定から初期化されます。

## 間隔と回数の読み方

間隔は**処理の開始から次の開始までの目標時間**です。例として、200ms指定で処理に25msかかった場合、残りの約175msを待つ考え方です。処理やOSの都合で、実測は目標を超えることがあります。処理に240msかかった場合に、遅れを取り戻すため並列送信することはありません。

「待機なし」は処理終了後の追加待機を省く設定で、0msで無制限に操作できるという意味ではありません。「平均開始間隔」は成功した処理の開始時刻どうしから算出します。YouTube側の受理間隔ではありません。

ランダムは1回ごとに5種類から選びます。同じ種類が続く場合もあり、5種類を順番に使う設定ではありません。

「操作済み」はボタン操作が完了した数です。YouTubeが受理した数は確認していません。結果不明になった操作は、自動的に再送しません。

## 中止が確定するタイミング

実行途中でEscを押しても、すでに依頼したボタン操作を取り消せるとは限りません。現在の結果を確認してから終了します。

ボタン登録では、保存前に中止を受け付けた場合は以前の登録を維持します。保存確定後の中止では保存を取り消さず、同期後の保存済み結果を表示します。保存後の同期に失敗した場合もDBの登録は残り、次の操作時に再同期します。

認識・保存に失敗する場合は[症状別の確認](maintenance.md#症状から確認する)へ進んでください。
