# YouTube チャットヘルパー

YouTubeライブチャットで、登録した弾幕の入力とリアクションボタンの操作を補助するWindows用ツールです。

投稿者ごとの弾幕と、どのチャンネルでも使う共通弾幕を管理できます。表示中の動画から投稿者を判別し、関連付けた設定へ切り替えます。

**弾幕は入力のみです。送信はYouTube側で行います。リアクションはボタン操作まで実行します。**

## はじめに

必要なものは、Windows、AutoHotkey v2、Windows PowerShell 5.1、YouTubeを開くブラウザーです。AutoHotkey v1では動作しません。

1. 配布物を、書き込み可能なフォルダーへ展開します。
2. すべての `.ahk`・`.ps1` を同じフォルダーに置き、`main.ahk` を起動します。
3. YouTubeの動画ページを開き、チャット入力欄をクリックします。
4. **Ctrl＋Alt＋Q** でパネルを開きます。

初回は投稿者・弾幕ともに0件です。設定ファイルは自動作成されます。

まず試すなら「弾幕ライブラリ」で「共通の弾幕」を選び、「追加」から好きな文字列を登録してください。チャット入力欄をクリックして **Ctrl＋Alt＋3** を押すと、共通弾幕の1番目を入力します。

ブラウザー判定の対象はChrome・Edge・Firefox・Brave・Opera・Vivaldiです。すべてのバージョンで動作を保証するものではありません。動画URLやリアクションメニューの検出可否は、ブラウザーとYouTubeの表示状態に依存します。

## 主な操作

| キー | 操作 |
|---|---|
| Ctrl＋Alt＋Q | パネルを開く／実行中の進捗を表示 |
| Ctrl＋Alt＋1・2 | 投稿者別弾幕の1番目・2番目を入力 |
| Ctrl＋Alt＋3・4 | 共通弾幕の1番目・2番目を入力 |
| Ctrl＋Alt＋R | リアクションを実行（変更可能） |
| Esc | リアクションを停止／パネルを隠す |

弾幕・リアクションのキーは、対象ブラウザーが最前面のときに有効です。該当する弾幕が未登録なら入力しません。

パネルの×は画面を隠します。アプリを終了するには、タスクトレイのアイコンを右クリックして「Exit」を選びます。

## 初期設定

| 項目 | 値 |
|---|---|
| 投稿者／投稿者別弾幕／共通弾幕 | すべて0件 |
| 投稿者の自動判別 | ON（チャンネルとの関連付けは未登録） |
| リアクション | ハート、1回、操作後の待ち時間25ms |
| リアクションキー | Ctrl＋Alt＋R |

自動判別ONで投稿者別弾幕を使うには、チャンネルとの関連付けが必要です。共通弾幕と共通リアクションは投稿者未登録でも使えます。リアクションの初回利用には、ブラウザーの操作ボタン登録が必要です。

## データの扱い

個人設定・ボタン登録・動画情報キャッシュはアプリと同じフォルダーに保存します。これらはGitの管理対象から除外しています。動画の投稿者判別では、必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。

リアクションの「操作済み」はボタン操作の完了数です。YouTube側で受理された回数を保証する表示ではありません。
