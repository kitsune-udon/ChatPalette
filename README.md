# ChatPalette

YouTube向けの弾幕入力・リアクション補助ツール。

YouTubeのチャット欄・コメント欄への弾幕入力と、ライブのリアクションボタン操作を補助するWindows用ツールです。

配信者ごとの弾幕と、どのチャンネルでも使う共通弾幕を管理できます。表示中の動画から配信者を判別し、連携した設定へ切り替えます。

**弾幕は入力のみです。送信はYouTube側で行います。リアクションはボタン操作まで実行します。**

## はじめに

必要なものは、Windows標準SQLiteを備えるWindows 10以降、AutoHotkey v2、Windows PowerShell 5.1、YouTubeを開くブラウザーです。動作検証はWindows 11・64bit版AutoHotkey v2で行っています。32bit版・ARM環境は未検証です。SQLiteの別途インストールは不要です。AutoHotkey v1では動作しません。

1. 配布物を、書き込み可能なフォルダーへ展開します。
2. 展開したフォルダー構成を保ったまま、`main.ahk` を起動します。`src/` 内のソース一式と `VERSION` は実行に必要です。
3. YouTubeの動画ページを開き、チャット欄またはコメント欄をクリックします。
4. **Ctrl＋Alt＋Q** でパレットを開きます。

初回は配信者・弾幕ともに0件です。設定ファイルは自動作成されます。

まず試すなら「弾幕を追加・編集」で「共通の弾幕」を選び、「追加」から本文を登録します。Ctrl＋Alt＋3を使う場合は編集画面で割り当てます。パレットの一覧からも選んで入力できます。

ブラウザー判定の対象はChrome・Edge・Firefox・Brave・Opera・Vivaldiです。すべてのバージョンで動作を保証するものではありません。動画URLやリアクションメニューの検出可否は、ブラウザーとYouTubeの表示状態に依存します。

## 主な操作

| キー | 操作 |
|---|---|
| Ctrl＋Alt＋Q | パレットを開く／実行中の進捗を表示 |
| Ctrl＋Alt＋1・2 | 割当1・2の配信者別弾幕を入力 |
| Ctrl＋Alt＋3・4 | 割当1・2の共通弾幕を入力 |
| Ctrl＋Alt＋R | リアクションを実行（変更可能） |
| Esc | リアクションを停止／パネルを隠す |

弾幕・リアクションのキーは、対象ブラウザーが最前面のときに有効です。該当する弾幕が未登録なら入力しません。

パレットは入力用、管理画面は弾幕・配信者の編集用です。管理画面の配信者選択は入力対象を変えません。主画面は表示領域に合わせて配置を調整し、小さいウィンドウではスクロールできます。キーボードで移動した操作部も自動表示します。

画面の×はその画面を隠します。アプリを終了するには、タスクトレイのアイコンを右クリックして「Exit」を選びます。

バージョン：0.4.4。変更点は [変更履歴](CHANGELOG.md) を参照してください。

## 初期状態

配信者・弾幕は0件で、自動判別はONです。配信者別弾幕を自動判別で切り替えるには、チャンネルとの連携が必要です。自動判別OFFでは、チャンネル連携なしで配信者を手動選択して使えます。共通弾幕は配信者未登録でも使えます。リアクションは全チャンネル共通です。初回利用には操作ボタン登録が必要です。パレットで今回の条件を変更でき、キー実行は保存した標準設定を使います。

設定値の詳細は[利用ガイド](docs/user/guide.md#初期設定と画面の終了)を参照してください。入力欄を識別できない場合は入力を停止します。検索欄やアドレス欄を検出した場合も停止します。検証と文字入力は別処理のため、入力が終わるまで入力欄を切り替えないでください。

## データの扱い

個人設定・ボタン登録はアプリの `data/` フォルダーに保存します。動画情報のキャッシュは常駐プロセスのメモリだけに保持し、ファイルへ保存しません。設定とリアクションボタン登録はSQLite（DELETE＋EXTRA）の `data/settings.db` へ保存します。初回は既存の `data/settings.ini` を検証して移行し、元INIを変更せず残します。旧配置のファイルは自動探索しません。これらはGitの管理対象から除外しています。動画の配信者判別では、必要に応じて動画IDを含むURLでYouTubeのoEmbedへ問い合わせます。

リアクションの「操作済み」はボタン操作の完了数です。YouTube側で受理された回数を保証する表示ではありません。
